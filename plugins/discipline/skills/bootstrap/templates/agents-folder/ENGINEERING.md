# This project's engineering principles

The generic principles E1–E10 (how we build, whatever the stack) come from the discipline plugin:
/discipline:engineering in Claude Code, or `discipline doc engineering`. Cite them by number in
decisions, proposals and review findings. The short, binding form is in `CLAUDE.md`.

This file holds the principles specific to this product, numbered on after the generic ones, each with
the reason. A rule here that would hold in any project belongs in the plugin instead.
