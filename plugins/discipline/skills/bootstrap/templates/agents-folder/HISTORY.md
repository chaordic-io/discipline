# History

The order in which things were built. The reasoning for each item is in `docs/decisions/`
(indexed in `docs/DECISIONS.md`); this file is the timeline that ties them together.

**Sessions read the last three entries;** the older ones are reference. Keep each to a few lines with
pointers, not a retelling. Past the budget (200 lines), move the oldest entries to `docs/history.md`
and leave one line here pointing to it.
